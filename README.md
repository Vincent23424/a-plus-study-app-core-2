# A+ Core 2 Study App

CompTIA A+ Core 2 (220-1202) study PWA for Modules 11–22.

## Version 1.1.0

- 120 questions total — 10 questions per module
- English interface and study content
- Questions grounded only in the uploaded CompTIA A+ Core 2 Student Guide and Core 2 (220-1202) Exam Objectives
- Module practice
- Final Test
- Random Practice
- Wrong Questions
- Weak Areas
- Starred Questions
- New Questions
- Module Challenge with selectable 3-module ranges and an optional extra module
- Question counts: 10 / 20 / 30 / 50 / 75 / 100 / 150 / 200 / 250 / 300 / All available
- No duplicate question IDs within a generated session
- Shuffled answer positions
- Confirm Answer + explanation before continuing
- Back button
- Session score calculated from the current session only
- Retry starts a fresh randomized version of the same session pool
- Local progress via localStorage
- Responsive mobile layout
- Dark/light theme
- PWA/offline caching

## Source rule

The learning content in `questions.json` is authored from the provided CompTIA A+ Core 2 Student Guide and the provided CompTIA A+ Core 2 (220-1202) Exam Objectives, Version 4.0. No outside study content is intentionally added.

## GitHub Pages

Upload the files in this folder to a repository and enable GitHub Pages. The app is static and does not require a server.
