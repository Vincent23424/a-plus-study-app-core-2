# CompTIA A+ Core 2 Study App

Personal study app for **CompTIA A+ Core 2 (220-1202)**.

A browser-based study tool covering **Core 2 Modules 11–22**, with quizzes, flashcards, PBQ-style labs, references, statistics and progress tracking.

## Features

* Core 2 Modules 11–22
* Module practice
* All Modules practice
* Adjustable question count
* Flashcards
* PBQ & Lab exercises
* Command-prompt-style terminal
* Reference section
* Ports & protocols
* Windows commands and tools
* Study Readiness 0–100%
* Statistics and accuracy tracking
* Weak-area tracking
* Starred questions
* Random practice
* Local progress saving
* Responsive desktop/mobile design
* Back navigation
* GitHub Pages support
