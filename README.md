# CompTIA A+ Core 2 Study App

Personal study app for CompTIA A+ Core 2 (220-1202), covering Modules 11–22.

## Features
- Module and All Modules practice
- Flashcards with module/count selection
- PBQ & Lab terminal exercises
- Reference section
- Study Readiness 0–100%
- Statistics, weak areas and starred questions
- Local progress saving
- Responsive design and back navigation
